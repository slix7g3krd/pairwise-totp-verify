# pairwise-totp-verify

TOTP 二次验证一上线，验证码校验就开始放水：窗口开到前后各 5 个周期，旧码能反复用；比较用 ==，长度不同还会提前返回；同一个码可以在多个账号间复用；备份码明文存库且能无限次尝试；锁定只按用户名计数，换 IP 继续爆破；服务器用本地时区生成时间片，夏令时切换后全员验证失败；密钥长度不足 16 字节也没有拒绝；校验失败不区分“码错”和“码已用过”；并发请求同时消费同一个码；恢复流程还能绕过二次验证。security/totp_verify.py 是核心，tests/test_totp_verify.py 15个红。要修的是：RFC 6238 时间片；±1 窗口；重放缓存；常量时间比较；备份码哈希且一次性；按账号+IP 锁定；UTC 时间源；密钥长度；错误分类；原子消费；恢复流程强制二次验证。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
